### Types de vulnérabimités

- Operating System : Ces types de vulnérabilités se trouvent dans les systèmes d'exploitation (OS) et entraînent souvent une élévation de privilèges.
- (Mis)Configuration-based : Ces types de vulnérabilités proviennent d'une application ou d'un service mal configuré. Par exemple, un site web exposant les données personnelles de ses clients.
- Weak or Default Credentials : Les applications et services comportant un système d'authentification sont livrés avec des identifiants par défaut lors de leur installation. Par exemple, un tableau de bord d'administration peut utiliser le nom d'utilisateur et le mot de passe « admin ». Ces informations sont facilement devinables par un attaquant. 
- Application Logic : Ces vulnérabilités résultent d'applications mal conçues. Par exemple, des mécanismes d'authentification mal implémentés peuvent permettre à un attaquant d'usurper l'identité d'un utilisateur.
- Human-Factor : Les vulnérabilités liées aux facteurs humains sont des vulnérabilités qui exploitent le comportement humain. Par exemple, les courriels d'hameçonnage sont conçus pour tromper les humains et leur faire croire qu'ils sont légitimes.
  
### CVSS (Common Vulnerability Scoring System )

- None : 0
- Low : 0.1-3.9
- Medium : 4-6.9
- High :7-8.9
- Critical : 9-10
